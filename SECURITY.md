# Security policy

This repository is public by design and contains no secrets.

Do not open a public issue containing internal system information, clinical
data, credentials, private source, or production payloads. Remove exposed
material from public view and notify the repository owner privately.

Treat an unauthorized catalog change, validator bypass, workflow-pin change,
delivery-host substitution, or secret exposure as release blocking. Anything
delivered to a browser is inspectable and must not contain a privileged
credential.
